# Smart-Plant-Monitoring-and-Watering-System
ESP32-based Smart Plant Monitoring & Watering System with Automated Irrigation, IoT Monitoring, PCB Design, and CAD Enclosure Design.

## Overview

The Smart Plant Monitoring & Watering System is an ESP32-based IoT solution designed to automate plant care while providing environmental monitoring and interactive user engagement. The system continuously monitors soil moisture, temperature, humidity, and water tank level, automatically watering the plant when required and alerting the user when the water reservoir is low.

In addition to automation, the project incorporates interactive OLED expressions that respond to touch and proximity detection, creating a more engaging user experience. The project also includes a custom PCB designed using EasyEDA and a complete product enclosure designed using Onshape.

## Features

* Automatic plant watering using soil moisture monitoring
* Water tank level monitoring using an ultrasonic sensor
* Low-water buzzer alert system
* Temperature and humidity monitoring using DHT11
* OLED dashboard displaying real-time sensor readings
* Interactive OLED eye expressions
* Touch-based expression changes
* IR-based proximity detection
* IoT monitoring through Blynk
* Custom PCB design using EasyEDA
* Custom enclosure design using Onshape
